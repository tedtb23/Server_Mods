To install follow these steps:

  1. Visit the link to download fabric.
  2. Run the downloaded file and follow the installer steps to install fabric.

  3. Download the mods found in the other links. The links go to CurseForge which allows you to pick manual download, where you should choose the options for 26.3 and fabric.
    OR
    Instead of opening each link for each mod manually, you can download the manifest file. This works with the CurseForge app to automatically download all the mods in the modpack.

  4. If downloading the mods manually simply place the downloaded .jar files into the mods folder of your .minecraft installion. (C:\Users\"username"\AppData\Roaming\.minecraft\mods)
